\section*{Data, scripts, code and supplementary information availability}
The code, the deposited outputs, the frozen protocols of the computations and the Lean files are available at \url{https://github.com/MomenAhmed05/dip-test-calibration} and archived on Zenodo at \url{https://doi.org/10.5281/zenodo.24537718} (version 1.0.0, the snapshot of commit \texttt{add0336}). The repository README lists which script and which deposit give each number, table and figure in the paper, and how to rerun them. The figures are plots of the deposited outputs, drawn by \texttt{paper/figs/make\_figs.py}; no figure was generated by an AI model.
